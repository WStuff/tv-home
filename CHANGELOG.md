# Changelog

All notable changes to TV Home are documented here. The project follows semantic versioning.

## [1.0.0] — 2026-10-21

### Added

- Universal Android TV / Google TV package with no preselected personal apps.
- Remote-friendly first-run setup in English and Russian.
- Language, dock, Home-app, background, and final confirmation screens.
- Four-app glass dock with a soft lower-screen gradient.
- Five built-in 16:9 backgrounds.
- Configurable Home list and separate **All apps** catalogue.
- On-TV launcher settings, app reordering, network status, inputs, and clock screensaver.
- GitHub Actions workflows for CI and signed releases.
- Public installation, privacy, security, contribution, and release documentation.

### Privacy

- No advertising, analytics, accounts, bundled user identifiers, or `INTERNET` permission.
