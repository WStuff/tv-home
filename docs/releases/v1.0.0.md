# TV Home 1.0.0

The first public release of TV Home: a calm, configurable Home screen for Android TV and Google TV.

## Highlights

- Universal APK with no preselected personal apps or device-specific setup.
- English and Russian first-run experience.
- Four-app glass dock and configurable Home list.
- Five built-in backgrounds.
- **All apps** catalogue for everything not pinned to Home.
- Remote-first navigation, Inputs, network status, system Settings, and clock screensaver.
- No ads, analytics, accounts, content feeds, or `INTERNET` permission.

## Requirements

- Android TV or Google TV 8.0 / API 26 or newer.
- A device that permits installation of third-party APKs.
- Default-Home replacement depends on manufacturer firmware.

## Install

Download both release assets, verify the checksum, then follow [the installation guide](../INSTALL.md).
