# TV Home support

Start with the [installation guide](docs/INSTALL.md) and [troubleshooting guide](docs/TROUBLESHOOTING.md). When requesting help, include:

- TV or streaming-device model.
- Android TV / Google TV version.
- TV Home version.
- What you expected and what happened.
- Exact steps that reproduce the problem.

Screenshots are welcome, but remove IP addresses, Wi-Fi names, account names, device identifiers, and other private information first.

Use GitHub Issues for reproducible bugs and feature requests. Security reports must follow [SECURITY.md](SECURITY.md).
